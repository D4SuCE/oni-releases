# Oni — выпуски

Установщики Oni, неофициального клиента Яндекс Музыки для Windows.
Не связан с Яндексом. Для полных треков нужна подписка Яндекс Плюс.

Скачать — на странице [Releases](https://github.com/D4SuCE/oni-releases/releases/latest):

- `Oni-Setup-<версия>.exe` — установщик. Обновляется сам: новая версия скачивается
  в фоне и ставится при выходе из программы.
- `Oni-<версия>-portable.exe` — без установки, обновляется вручную.

Программа не подписана, поэтому при первом запуске Windows SmartScreen может показать
«Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

Здесь только готовые программы, код — в отдельном репозитории.
